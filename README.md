# 🎮 گیم سنتر — دفتر روزانه باشگاه بازی

نرم‌افزار حسابداری روزانه برای باشگاه بازی با چهار دستگاه.
همه‌چیز فارسی و راست‌به‌چپ است، اینترنت لازم ندارد و همهٔ اطلاعات روی همان کامپیوتر
در فایل‌های سادهٔ JSON ذخیره می‌شود.

- تایمر و **هزینهٔ لحظه‌ای** هر دستگاه
- تسویه با نوشیدنی، خوراکی و مورد دلخواه
- دفتر روز، آرشیو روزهای بسته‌شده، خروجی Excel (CSV) و نسخهٔ چاپی
- محاسبهٔ پول در دو جا انجام می‌شود (مرورگر و سرور) اما با **یک فرمول مشترک**،
  پس مبلغی که روی صفحه می‌بینید دقیقاً همان مبلغی است که در دفتر ثبت می‌شود.

---

## ۱) نصب روی ویندوز — ساده‌ترین راه

فقط یک فایل لازم است و **نیازی به نصب پایتون یا مرورگر خاص نیست**.
(Edge روی ویندوز ۱۰ و ۱۱ از قبل هست و برنامه از همان استفاده می‌کند.)

1. وارد صفحهٔ **Releases** همین مخزن شوید
   (`https://github.com/Christosanesti/BizBizClubBundle/releases`).
2. از آخرین نسخه، فایل **`GameCenter.exe`** را دانلود کنید.
3. یک پوشهٔ دائمی بسازید (مثلاً `C:\GameCenter`) و فایل را داخل آن بگذارید.
   ⚠️ فایل را از داخل فایل‌های زیپ‌شده مستقیم اجرا نکنید؛ اول استخراج کنید.
4. روی `GameCenter.exe` **دوبار کلیک** کنید.

چند ثانیه بعد، پنجرهٔ برنامه باز می‌شود (مثل یک برنامهٔ دسکتاپ، بدون نوار آدرس).

> **پیام آبی Windows SmartScreen**
> چون فایل exe امضای دیجیتال تجاری ندارد، ویندوز ممکن است پیام
> «Windows protected your PC» نشان دهد.
> روی **More info** بزنید و بعد **Run anyway**.
> این پیام فقط یک‌بار ظاهر می‌شود.

> اگر پنجره باز نشد، فایل گزارش را ببینید:
> `%LOCALAPPDATA%\GameCenter\server.log`

### اجرای دوباره
هر بار فقط روی همان `GameCenter.exe` دوبار کلیک کنید. اگر برنامه از قبل در حال اجرا
باشد، نسخهٔ جدید خودش را به پنجرهٔ باز وصل می‌کند و چیزی خراب نمی‌شود
(تایمرهای در حال اجرا از دست نمی‌روند).

---

## ۲) استفادهٔ روزانه — سه قدم

### شروع بازی
روی کارت دستگاه، تعداد **دسته** (۱ تا ۴) را انتخاب و «شروع بازی» را بزنید.
تایمر و هزینهٔ لحظه‌ای همان‌جا نمایش داده می‌شود.
میان‌بر: کلیدهای `۱` تا `۴`.

### تسویه
«پایان و تسویه» → مدت، تعداد دسته و هزینهٔ بازی محاسبه می‌شود؛
روی نوشیدنی‌ها بزنید تا به صورتحساب اضافه شوند (چند بار = چند عدد)؛
برای مورد خارج از منو، نام و مبلغ را در «مورد دلخواه» بنویسید.
دکمهٔ «ثبت و آزادسازی دستگاه» ردیف را در دفتر روز ثبت می‌کند.

اگر مشتری بدون بازی رفت یا اشتباه شروع شد، با **✕** کنار دکمهٔ تسویه، بازی
**بدون محاسبه** لغو می‌شود.

### پایان شب
«بستن روز» جمع صندوق را نشان می‌دهد؛ با تأیید شما حساب روز در «دفتر روزها»
بایگانی می‌شود و دفتر تازه‌ای باز می‌شود.

---

## ۳) بستن کامل برنامه

بستن پنجرهٔ مرورگر، **سرور را خاموش نمی‌کند** (به‌عمد؛ تا تایمرهای در حال اجرا
از دست نروند). برای خاموش کردن کامل:

- در پوشهٔ همان فایل، یک `cmd` باز کنید و بزنید:
  ```
  GameCenter.exe --stop
  ```
- یا در **Task Manager** فرایند `GameCenter.exe` را End task کنید.

اگر می‌خواهید ویندوز هنگام روشن شدن، برنامه را خودکار باز کند، فایل exe را در
پوشهٔ Startup کپی کنید (`Win+R` → `shell:startup`).

---

## ۴) محل ذخیرهٔ اطلاعات و پشتیبان‌گیری

روی ویندوز:

```
%LOCALAPPDATA%\GameCenter\
├── settings.json        قیمت‌ها و منوی نوشیدنی
├── running.json         بازی‌های در حال اجرا (تایمرها)
├── days\current.json    دفتر امروز
├── days\*.json          روزهای بایگانی‌شده
├── browser-profile\     پروفایل پنجرهٔ برنامه
└── server.log           گزارش سرویس
```

**پشتیبان‌گیری:** کل پوشهٔ `GameCenter` را کپی کنید (فلش یا فضای ابری).
برای بازگردانی، همان پوشه را سر جایش برگردانید.
اگر می‌خواهید اطلاعات جای دیگری باشد، متغیر محیطی `GAMECENTER_DATA` را به مسیر
دلخواه تنظیم کنید.

## ۵) فرمول محاسبه (دقیقاً چه چیزی حساب می‌شود؟)

```
هزینهٔ بازی = نرخ ساعتی × دقیقه‌های محاسبه‌شده ÷ ۶۰
جمع ردیف   = هزینهٔ بازی + جمع نوشیدنی‌ها
جمع روز    = جمع همهٔ ردیف‌ها
```

- **نرخ ساعتی** برای ۱/۲/۳/۴ دسته در تنظیمات تعیین می‌شود و لحظهٔ **شروع** بازی
  ثبت می‌شود؛ تغییر قیمت‌ها روی بازی‌های در حال اجرا اثر ندارد.
- **گرد کردن زمان** (تنظیمات): دقیق، هر ۵/۱۰/۱۵/۳۰/۶۰ دقیقه به بالا، یا
  نزدیک‌ترین. نیمه‌ها همیشه **به بالا** گرد می‌شوند (۲٫۵ → ۳) — هم در مرورگر و
  هم در سرور.
- **حداقل زمان محاسبه**: مثلاً اگر ۱۵ دقیقه بگذارید، حتی بازی کوتاه‌تر هم ۱۵ دقیقه
  حساب می‌شود.
- مبلغ‌ها به تومان و به عدد صحیح گرد می‌شوند (نیم به بالا).

هنگام تسویه، لحظه‌ای که روی «ثبت» می‌زنید «زمان پایان» است و همان لحظه در دفتر
ثبت می‌شود؛ پس مبلغ روی صفحه با مبلغ ثبت‌شده یکی است.

## ۶) ساخت مجدد فایل exe

### الف) با GitHub Actions (پیشنهادی، بدون نصب چیزی)
هر بار که کدی به شاخهٔ `main` push شود، فایل ویندوزی ساخته و تست می‌شود.
با ساختن یک تگ (مثل `v1.0.0`) همان فایل به بخش **Releases** هم اضافه می‌شود:

```
git tag v1.0.0
git push origin v1.0.0
```

فایل ساخته‌شده در تب **Actions** → آخرین اجرا → **Artifacts** هم قابل دانلود است.

### ب) روی ویندوز، به‌صورت لوکال
پایتون ۳٫۱۲ را نصب کنید، بعد در پوشهٔ پروژه:

```
python -m pip install pyinstaller
python -m PyInstaller --clean --noconfirm packaging\gamecenter.spec
```

خروجی: `dist\GameCenter.exe`

### ج) ساخت فایل ویندوزی از لینوکس/مک
اسکریپت `packaging/build_windows.sh` همین کار را داخل Docker + Wine انجام می‌دهد
(به اینترنت نیاز دارد):

```
./packaging/build_windows.sh
```

---

## ۷) اجرا روی لینوکس

```
./run.sh
```

یا مستقیم:

```
python3 app.py --port 8777
```

سپس مرورگر را روی `http://127.0.0.1:8777` باز کنید.
`run.sh` خودش سرویس را بالا می‌آورد و پنجرهٔ برنامه را با Chromium باز می‌کند.
اطلاعات روی لینوکس در `~/.local/share/gamecenter` ذخیره می‌شود.

---

## ۸) اگر مشکلی پیش آمد

| مشکل | راه‌حل |
|---|---|
| پنجره باز نمی‌شود | `%LOCALAPPDATA%\GameCenter\server.log` را ببینید |
| «Windows protected your PC» | More info → Run anyway |
| پیام «پورت اشغال است» | برنامهٔ دیگری روی پورت ۸۷۷۷ است؛ آن را ببندید یا `GameCenter.exe --port 9000` |
| برنامه دو بار باز نمی‌شود | درست است؛ نسخهٔ دوم به همان پنجره وصل می‌شود |
| می‌خواهم از اول شروع کنم | پوشهٔ `%LOCALAPPDATA%\GameCenter` را (پس از پشتیبان) پاک کنید |
| تست‌ها | `python -m unittest discover -s tests -p "test_*.py"` |

## ساختار مخزن

```
.
├── app.py                     سرویس محلی (پایتون، بدون وابستگی بیرونی)
├── billing.py                 تمام محاسبات پول و زمان
├── ui/
│   ├── index.html
│   ├── style.css
│   ├── app.js
│   ├── billing.js             همان فرمول، برای مرورگر (آینهٔ billing.py)
│   ├── icon.svg
│   └── vendor/                GSAP و Confetti (آفلاین)
├── packaging/
│   ├── gamecenter.spec        تنظیمات ساخت exe
│   ├── gamecenter.ico
│   ├── version_info.txt
│   └── build_windows.sh       ساخت ویندوزی از لینوکس (Docker + Wine)
├── tests/                     تست‌های پول، دفتر و سرویس
├── .github/workflows/windows.yml
└── run.sh                     اجراکنندهٔ لینوکس
```

میان‌برها: `۱`…`۴` شروع/تسویهٔ دستگاه، `Esc` بستن پنجره‌ها.
